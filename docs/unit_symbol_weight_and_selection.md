# 算子图标与选中反馈（v20）

## v20：跨地图坦克重量展示

旧版把 Map123 注册表的 `2_0 → 重型坦克` 当作所有地图的固定重量，因此中型、轻型坦克也显示 H。现在只对已映射为坦克的 Source `2_0`，读取已公开投影的 `name` 精确匹配：

- `重型坦克`：坦克 + H。
- `中型坦克`：坦克 + M。
- `轻型坦克`：坦克 + L。
- 缺失或未知名称：普通坦克图标，不添加重量字母。

这只是展示细分，不修改 Source 身份或裁决。不会读取隐藏 raw 属性，不以装甲数值、武器、任意名称子串猜测重量；未知 Source 类型仍是 UNKNOWN。live 与 replay 均已投影原始名称，共用同一解析器。其他注册表类别保持原有展示。

重型、中型保留差异车体轮廓；轻型用普通坦克轮廓加 L。SVG 缓存键包含实际图层，三类不会相互污染。

## 紧凑动作框

双人控制页把圆形动作按钮放入现有右侧栏底部的四列小矩形，不占地图；每个按钮保持 46px。移动地图或算子离开视野不会移动动作框。再次点击同一算子仍收起/展开动作；可用动作、活动高亮、路线确认、过期预览和提交去重继续由原控制器管理。窄屏右侧栏按原布局排列到地图下方。旧单页控制也改用地图右下的小矩形。

## 选中反馈

选中与攻击预览保持当前地图缩放层级，尺寸仍只放大为未选中的 1.12 倍；总览不强制放大图标。候选攻击对象的红色虚线与己方选中的黄色描边分开。

## 验证范围

Node 检查覆盖 Map123 的 49 个算子、同一 `2_0` 的 H/M/L、缺失/未知名称、未知编码、缓存图层、动作框脱离地图坐标、重复点击和既有 13 类操作流程。轻型 SVG 通过静态资源加载检查。未将这些 DOM/代码测试称作浏览器截图验收。
