本次是相对于已交付 v3 源码的覆盖更新，不包含 Map123 展开数据、缓存或历史运行目录。
停止正在运行的引擎并等待回放保存完成，再替换源码。不要在活动对局中覆盖文件。

## 游戏规则

- `SHOOT` 使用 `target_id` 或 `target_hex` 二选一。只给格子代表空炮，不查询该格占用者来补选目标。
- 空炮正常检查可用武器、弹药和冷却等条件，正常消耗资源，但不产生伤害或压制。
- 显式选中的目标仍须满足伤害生效条件；超出有效射程的空耗射击不造成伤害。
- 空炮暴露信号持续 10 个引擎结果帧，不是 10 次网页刷新，也不是固定 10 秒。信号消失不意味着本来就在正常视野内的单位被强行隐藏。
- `INDIRECT_FIRE` 保留目标格并允许显式 `target_id`。没有显式目标的玩家/Agent 指令按空炮处理，不自动对落点单位造成伤害。
- 普通有效射击、特殊武器及其他动作的合法性检查不能因为允许空炮而被绕过。

## 原版 Map123 炮兵弹药

原版 Map123 的炮兵武器 72 使用弹药键 `0`，初始数量确实为 0。旧代码只检查弹药映射存在，导致预检显示可用，实际执行却拒绝。本次修正预检，不给原版偷偷补弹药。

完整射击流程使用仓库已有的显式测试变体验证：

```bash
RUN_ID="map123-ammo2-$(date +%Y%m%d-%H%M%S)"
RUN_DIR="$(pwd)/local_data/map123/runs/$RUN_ID"
python -m scripts.run_map123 --scenario artillery-ammo2 --output-dir "$RUN_DIR" --run-namespace "$RUN_ID" --port 8003
```

研究和标准数据体验仍用 `--scenario original`。测试变体不是原版基准数据，比较结果时必须记录场景与规则版本。

## 界面与分类

选中只放大至原尺寸 1.12 倍并标黄，不再从总览点强制跳至大图标。中型与重型图形具有不同轮廓及单/双横杠辅助标识。Map123 原始数据没有中型坦克，不能凭名称猜测 Source 类型编码；参见 `unit_symbol_weight_and_selection.md`。

## 接口和历史复盘

新增位置空炮与间瞄显式目标字段，旧的目标直射调用方式继续有效。裁决语义升级为 `native-joint-prestate/1.4`，旧语义动作档案不能被当前引擎当作同一规则严格重演。历史文件不会删除；需要旧规则严格重演时使用覆盖前备份或原 v3 源码。已记录的展示帧与重新执行动作是不同用途。
