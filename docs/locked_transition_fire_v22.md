# v22 锁定武器过渡状态射击补丁

软件版本 **0.4.22.1**；裁决语义 **`native-joint-prestate/1.11`**。
这是用户指定的规则变更，不是与旧裁决等价的性能改写。

## 射击与武器操作分开

- 完成锁定并绑定到所选武器后，普通直射（包括对位置空射）允许在机动、停止转换、进入/退出行军姿态转换中开火；不再因这些转换返回 `ATTACKER_TRANSITIONING`。
- 锁定进行中只有预留的武器 ID，不表示锁定完成；仍不可射击。旧的无具体武器 ID 锁定，以及锁定的其他武器，继续拒绝。
- 射击不会取消机动路线、清除转换、提前完成停止或重置任何状态计时器。所有计时器仅按实际模拟时间推进。
- 展开、锁定、解除锁定及通过解锁重新选择武器，都要求停止、无活动移动/停止转换、无活动状态转换且未失控。展开新增与锁定/解锁一致的失控检查。
- 解锁或更换武器不补弹、不刷新普通冷却、引导恢复或间接火力计划冷却；各武器原有弹药键独立保留。

## 不变的边界

存活、部署/搭载、席位归属、目标可见性、目标类型、弹药、冷却和射程裁决不变。
普通直射超距仍只消耗射击资源并产生既有空射效果，不造成战斗伤害。
引导射击、间接火力和空中单位悬停仍保留原专用规则；失控状态下射击规则本次不改。
能力目录、对位置射击检查及冻结视图的火力效果估算复用同一权威就绪判断。

## 旧结果与更新

停止正在运行的对局后再安装，并为新规则新建对局。勿把运行中的内存状态当成已更新。
旧录像仍按已记录事实播放；严格动作重算及快照恢复拒绝 `/1.10` 等旧语义，且在应用动作前拒绝。
新 `/1.11` 轨迹可严格重算；不要将旧、新规则结果混作同一实验。
本补丁继承此前 v22 投影与射程覆盖层修复，不修改地图或用户想定原包。
